# Examen-juego-UNO-
Recreando el juego UNO en go para examen de la materia.

Este proyecto consiste en una versión simplificada del juego UNO desarrollada en Go. El programa permite que dos jugadores participen en una partida desde la consola utilizando un mazo de cartas generado y mezclado automáticamente.

Durante el juego, los jugadores deben colocar cartas que coincidan en color o valor con la carta que se encuentra sobre la mesa. Si no cuentan con una carta válida para jugar, deberán robar una carta del mazo. La partida continúa por turnos hasta que uno de los jugadores se queda sin cartas y gana la partida.
